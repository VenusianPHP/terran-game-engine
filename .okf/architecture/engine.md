# Engine

`GameEngine extends Voyager\Sketches\Sketch`, `#[Sketch('game')]`. `boot()`: `openTargets()` (default: every `config('terran.targets')` entry through `TargetOpener`), one `World::addViewport()` per target on `app('drawing')->renderer($entry['engine'], ['output' => $target])`, `World::setRoot(mainScene())`. `loop($mail)`: `QuitRequested` or `WindowClosed` for a window Terran opened → `STOP`; any `OwnedTarget::alive()` false → `STOP` (a window closed inside this turn's pump is gone before its `WindowClosed` reaches the mail); else `InputReader::read($mail, $world)` (when given), `World::tick($events, $delta)`, then `World::render()`. Each Viewport gets a `remint` closure (`drawing->renderer(engine, ['output' => $target])`) and the target's window name. `shutdown()`: `World::destroy()`, then every `OwnedTarget::close()`.

`GameLoop extends Voyager\IOPools\EventLoop`. `run()` sets the baseline, arms `every(1 / physics_hz, …, 'terran.physics')` then runs; the timer calls `advance()`: elapsed clock (hrtime, injectable) folds into whole steps of `stepNs() = round(1e9 / physics_hz)`, remainder kept; more than `max_physics_steps` (8) → run the cap, drop the backlog to the remainder. Each step: `physicsProcess(step)` on every attached Scene inside `hooks()` with `inPhysics()` true, then `afterStep()` callbacks in order (`inPhysics()` false). `hooks(Closure)` marks a hook pass; `until()` inside one throws `TerranException` (naming `world()->async()`) unless the caller is a fiber the loop owns — a hook cannot suspend its frame or step. `attach()` readies once, `detach()` exits once. `now()` is seconds since construction. `turn()` untouched. Bound as `'event-loop'` by `TerranServiceProvider::boot()` from IOPools' `loop-resource-registry`, `waiter-backend-mgr`, `promise-engine-mgr`, `mail-handler-mgr`; refuses if the loop was already resolved.

`World(GameLoop, ?SignalDispatcher, ?AutoloadRegistry, array $autoload_classes, ?InputMap)`: `setRoot()` resolves world-wide autoloads, then `wentLive()`; `wentLive()` resolves each Scene's `#[Autoload]`s, then attaches parent-first; `Scene::add()` / `remove()` on a live tree call `wentLive()` / `wentDead()`. `tick($events, $delta)` is one hook pass: each event walks the tree depth first until `input()` returns true, then goes to `signals->dispatch()`; then `process($delta)` depth first. A Scene freed earlier in a walk gets no further `input()` / `process()`; `wentLive()` skips attaching a Scene its parent's `ready()` removed; `advance()` skips a Scene detached earlier in the same step. `render()` draws every Viewport. `async($body)` is the loop's `async()`. `actions()` is the `InputMap`, or its `PhysicsLatch` while `inPhysics()`; the constructor registers the latch's `clear()` as an after-step callback. `wantsInput()`: a live Scene's class declares `input()` (reflection, cached per class). `viewportForWindow(?string)`. `destroy()` detaches the tree, drops the viewports, forgets autoloads.

`Viewport(name, OutputTarget, RenderingEngine, Color $background, ?Closure $remint, ?string $window)`: `render($root)` reads `target->pixelSize()`: zero → skip (no draw, no present); ≠ engine `width()/height()` → `engine = remint(target)` (no closure → `TerranException`), since an engine draws into the framebuffer it was made over. Then `engine->frame(clear + draw() depth first)` and `target->present()`. A throwing `draw()` drops the frame and skips present. `toPixels(x, y)`: on a `StagedWindow`, window points × `pixelSize / size`; other targets one to one.

`Scene(name)`: `ready / process / physicsProcess / input / exit / draw`; `add / remove (terminal) / parent / children / find('a/b') / path / walk`; `freed()` once a World let it go (remove or destroy); `add()` refuses a freed Scene; `actions()`; `autoload(class)`.

Interrupts (`Emits` trait on Scene, emit runs a snapshot of the connections so handlers may connect, disconnect or re-emit; dead targets are pruned from the live list after): `#[Interrupt(name, payload types)]`, repeatable, read up the class chain (child wins on a name), cached per class. Types: class names, `int float string bool array object callable mixed null`, `?T`. `emit()` checks name and payload, runs connections in order — a target that is a freed Scene, an array callable on one, or a closure bound to one, is skipped and dropped — then, when live and the World has signals, dispatches `SceneInterrupt` (`NamedSignal`, `terran.<path>.<interrupt>`). Wildcard listeners get `(name, [SceneInterrupt])`. `connect(name, callable)` or `connect(name, object, method)`; `disconnect()` matches by identity, or `==` for closures (one method of one object). Connections made before going live are kept; freeing a Scene severs its own.

Autoloads: `#[Autoload(class, as)]`, repeatable, read up the class chain, plus `terran.autoloads` (class → alias). `AutoloadRegistry(container)`: one instance per class per World; a `Scene` class is built as `new $class($as ?? lower short name)` and added under the root when it has no parent, so it is readied before the Scenes that declared it; a freed one is replaced by a new instance on next need; a second alias for the same Scene class throws naming both and who asked; others come from `container->make()`. `autoload()` refuses a Scene not live, or a class neither declared nor world-wide. A declaring Scene in a World with no registry throws on going live.

`TargetOpener(container, ?stager)`: kinds `staged` (`app('staged-windows')->open(name, width, height, options + title)`, with `options['toolkit']` = `terran.stager` when the target names none; null leaves Surface's `bridge.stage` default), `canvas` (`'canvas'` is a `TKCanvas`), `display` (`app('displays')->panel(panel, config, name, direct)`); `extend(kind, Closure)`. Returns `OwnedTarget(name, target, engine, window, close, alive)`. A staged window only shows while its toolkit session is pumped: the first staged window on a session joins `$window->session()` (a `Surface\Windows\StagedWindow`) to `app('event-loop')`, closing the last one Terran opened there calls `leaveLoop()`; a stager window without a session is closed and refused. Staged `alive()` is `isOpen()`.

Provider: `terran.actions` (`InputMap` from `terran.input.actions`), `terran.input` (`InputReader` over `app('human-input')`), `terran.world` (World with `app('signals')`, `AutoloadRegistry`, `terran.autoloads`, the map), `GameEngine` with the reader. Input detail: [input](input.md).

Config `terran.php`: `main_scene`, `refresh_rate` (null → `sketches.refresh_rate`), `physics_hz` (60), `max_physics_steps` (8), `stager` (null; `'appkit'`, `'sdl3'` or `'glfw'`), `autoloads` ([]), `targets` (default `main`: staged 960×540 "Terran" on velvet), `input.actions` ([]), `input.events` (`['keyboard', 'mouse']`).

Not yet: Scene2D/3D/UIControl and UIControls-first input walk (3), cameras, Renderer3D (slices 3–6).
